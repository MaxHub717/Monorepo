### ADM-006 — Season lifecycle controls
- Added proper lifecycle state management and transition enforcement:
  - DRAFT → REGISTRATION_OPEN
  - REGISTRATION_OPEN → REGISTRATION_CLOSED
  - REGISTRATION_CLOSED → ROSTER_LOCKED
  - ROSTER_LOCKED → ACTIVE
  - ACTIVE → PLAYOFFS
  - PLAYOFFS → COMPLETED
  - COMPLETED → ARCHIVED
- Added readiness gating and blocker messaging so invalid actions are disabled.
- Added fixture generation trigger while roster-locked.
- Core files:
  - [apps/web/app/seasons/[seasonId]/season-workspace.tsx](apps/web/app/seasons/[seasonId]/season-workspace.tsx)

## Overall outcome
The admin system now supports a complete operational loop:

- create/manage leagues
- create and configure seasons
- manage divisions
- accept and review participants
- lock the roster
- generate fixtures
- advance the season lifecycle

This gives the project a working admin operational foundation for competition management instead of only static dashboard scaffolding.
